# Certificate Management Routes

| Route | Fungsi |
|-------|--------|
| `/learning/certificates/user` | List sertifikat user (group by user, search, download PDF) |
| `/learning/certificates/template` | All-in-one: 4 tab |

## Tab Template Page
| Tab | Isi |
|-----|-----|
| **Pengaturan** | Logo, background, ttd upload + nama institusi + penandatangan + format nomor |
| **Template** | Upload template HTML & background per course + semua field override |
| **TTE** | Generate self-signed certificate + passphrase |
| **Kelola** | Aktif/nonaktif, hapus, filter, download PDF |

## Sidebar
```
👤 Sertifikat User  → /learning/certificates/user
🏆 Template Sertifikat → /learning/certificates/template
```
