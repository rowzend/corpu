# Sprint 3 — Admin Course Edit, Module/Lesson Management & Sequential Learning

**Date:** 2026-06-03
**App:** ASN CORPU (asncorpu)
**Context:** Admin course management, permission system debugging, module/lesson CRUD, sequential unlock learning flow

---

## Summary

Full-stack implementation of admin course edit page with module & lesson CRUD, quiz question management, sequential learning enforcement with unlock/lock mechanism, and debugging of permission-based sidebar rendering. Also fixed persistent browser extension error confusion and Tailwind/shadcn UI CSS variable configuration.

---

## Backend Changes

### QuizQuestion CRUD (views_api.py, serializers.py, urls_api.py)
- Built `QuizQuestionViewSet` (ModelViewSet) with writable nested QuizChoice serializer
- Added `QuizQuestionWriteSerializer` with create/update methods for nested choices
- Registered `/api/learning/quiz-questions/` route

### Sequential Learning (models.py, views_api.py)
- Added `Lesson.are_all_previous_completed(enrollment)` method
  - Flattens all course lessons ordered by `module.order_index` → `lesson.order_index`
  - Returns `True` if all lessons before `self` are completed by the enrollment
- `course_progress` action: returns `is_unlocked` per lesson
- `mark_complete` action: checks unlock status → returns 403 if locked
- Quiz `take` action: checks unlock status → returns 403 if prerequisites not met

### Permissions API Fix (views_api.py)
- `UserPermissionsAPIView`: superadmin bypass gated behind `PERMISSIONS_SUPERADMIN_OVERRIDE` setting
- Non-superadmin path reads `user.groups.first()` → `RoleRule` → `PermissionRule.module.nama_module`
- Verified: `Prakom@admin2025.com` has "learning" module via Super Admin group (206 RoleRules covering 10 modules)

### Module Serializer Fix (views_api.py, serializers.py)
- **Critical Bug:** `ModuleViewSet.list` used `ModuleListSerializer` which returned `lesson_count` but NOT `lessons` array
- Frontend accessed `mod.lessons.length` → `TypeError: Cannot read properties of undefined (reading 'length')`
- This error crashed the entire React tree (no error boundary), making sidebar disappear
- **Fix:** Changed `get_serializer_class` to always return `ModuleSerializer` (includes full `lessons` with `LessonListSerializer`)
  - Removed unused `get_serializer_class` conditional in `views_api.py`
  - Removed `ModuleListSerializer` import from `views_api.py`

### Course Thumbnail Migration
- Changed `ImageField` to `URLField` on Course model
- Migration created and applied

### Permission Seeding (management command)
- Seeded 34 learning PermissionRules
- Seeded 8 learning menu items
- Seeded 33 superadmin RoleRule assignments (full access)

## Frontend Changes

- 2 tabs: "Informasi Kursus" + "Modul & Pelajaran"
- Module management: add/edit/delete with title, description, order_index

### Quiz Questions Page (`(admin)/learning/quizzes/[id]/questions/page.tsx`)
- Full CRUD for quiz questions
- 3 question types: multiple_choice, true_false, essay
- Dynamic choices management for multiple_choice

### Learn Page (`(main)/courses/[slug]/learn/page.tsx`)
- Sidebar grouped by module (module_title headers)
- Lock icon + disabled click for locked lessons
- Lock overlay + disabled "Tandai Selesai" button when prerequisites not met
- Disabled quiz button when locked

### AdminSidebar (`components/admin/AdminSidebar.tsx`)
- Permission-based filtering: menu items have `requiredModules` array
- Filters via API `/management/permissions/user/` (returns `modules: string[]`)
- Loading skeleton state while permissions load
- Added `startsWith('http')` filter for logo image (prevents rendering relative URLs as `<img src>`)
- Added `onError` handler on logo `<img>` to hide on broken images
- **New menu item:** "Modul & Pelajaran" (📖) → `/learning/modules`

### New Page: `/learning/modules`
- Lists all courses with module count + lesson count
- "Kelola Modul & Pelajaran" button per course → links to course edit page
- Search, status filter support

### Image Error Handling (AdminSidebar, Navbar, DynamicFavicon, CourseCard, Footer)
- All `<img>` tags now have:
  - `startsWith('http')` check (skip relative/internal URLs)
  - `onError` handler that hides the broken image
- Fixes console errors from trying to load relative URLs as images

### CSS/Tailwind Fix (globals.css + tailwind.config.ts)
- **Problem:** shadcn/ui Dialog component uses `bg-background` class, but:
  1. CSS variable `--background` was not defined in globals.css
  2. Tailwind color `background` was not mapped in tailwind.config.ts
  3. Result: Dialog overlay worked (hardcoded `bg-black/80`) but Dialog Content had transparent background
- **Fix:**
  - `globals.css`: Added `@layer base { :root { --background: 0 0% 100%; ... } }` with all shadcn/ui CSS variables
  - `tailwind.config.ts`: Added `colors: { background: 'hsl(var(--background))', ... }` with all color mappings (background, foreground, primary, secondary, destructive, muted, accent, popover, card, border, input, ring)

## Debugging

### "Cannot read 'image.png'" Error
- **Root cause:** NOT from application code
- Searched entire codebase (frontend + backend) for `image.png` usage — zero results
- Also searched node_modules
- Error message format `"this model does not support image input"` indicates AI/image model browser extension
- User confirmed error persists in incognito → extension likely set to "Allow in incognito"
- **Resolution:** Advised user to disable browser extensions one by one

### AdminSidebar Not Showing
- Initially suspected permission issue → verified: `Prakom@admin2025.com` has "learning" module
- Real root cause: `TypeError` from `mod.lessons.length` crashed React tree
- Fixed by changing ModuleViewSet serializer to include `lessons`

## Key Decisions
- **Thumbnail:** URLField over ImageField — frontend always sends URL string
- **Sequential unlock:** Flat ordering (module.order_index → lesson.order_index), locked until all previous completed
- **Permission sidebar:** Hardcoded menuItems with `requiredModules` → filtered via API
- **Module serializer:** Always include full lessons data (no separate list/detail serializer)
