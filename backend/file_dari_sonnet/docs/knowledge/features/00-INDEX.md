## 🚀 Quick Navigation

### 💬 Comment System
- **2-Level Nesting**: Parent → Reply (max 2 levels)
- **Flat Structure**: Reply to reply otomatis flat ke level 1
- **Like/Dislike**: Real-time AJAX updates
- **Reply Form**: Dynamic form dengan JavaScript

### 👍 Engagement Features
- **Article Like/Dislike**: Toggle like/dislike dengan counter
- **Comment Like/Dislike**: Sama seperti artikel
- **Rating System**: 5-star rating dengan feedback
- **View Tracking**: Unique view per IP address

### ✅ Content Management
- **Approval Workflow**: Draft → Pending → Approved → Published
- **Content Types**: Article, Video, Document, Link
- **Rich Text Editor**: CKEditor dengan image upload
- **File Upload**: PDF, DOC, DOCX, PPT, XLS (max 100MB)

## 🎯 Use Cases

### For End Users
- Baca artikel knowledge base
- Comment dan reply ke comment
- Like/dislike artikel dan comment
- Rate artikel dengan feedback
- Share artikel

### For Content Creators
- Create artikel dengan rich text editor
- Upload images dan files
- Embed YouTube videos
- Submit artikel untuk approval
- Edit dan delete artikel

### For Approvers
- Review artikel yang di-submit
- Approve atau reject artikel
- Provide rejection reason
- View approval history

### For Administrators
- Manage categories dan tags
- Moderate comments
- View analytics (views, likes, ratings)
- Manage user permissions
