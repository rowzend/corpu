## ✨ Fitur Lengkap

Sistem ini memiliki **6 fitur utama**:

1. **👁️ View Count** - IP-based unique view tracking
2. **👍👎 Like/Dislike** - User engagement tracking
3. **⭐ Rating System** - 1-5 stars dengan feedback
4. **💬 Comment System** - Nested replies dengan like/dislike
5. **🎨 KMS Style UI** - Modern UI dengan author info & share
6. **✅ Approval System** - Validasi sebelum publish

# 1. Run migrations
